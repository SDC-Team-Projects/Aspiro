# Roadmap

## MVP (Weeks 7–10)

Core backend functionality required for the course demo.

* [x] User registration and authentication (JWT)
* [x] User and admin roles
* [x] Template management
* [x] Goal creation from templates
* [x] Automatic task scheduling based on template timing
* [x] Goal and task progress tracking
* [x] Update task status
* [x] User analytics dashboard
* [x] REST API with validation and exception handling

---

## Final Course Version (Weeks 11–14)

Features completed before the final presentation.

* [x] Complete security configuration and endpoint authorization
* [ ] Admin panel endpoints
* [x] Nested responses for goals and templates (stages and tasks)
* [x] Comprehensive testing (unit and integration)
* [x] API documentation 
* [x] Docker configuration
* [x] CI/CD pipeline
* [ ] Cloud deployment
* [ ] Final bug fixes and performance improvements
